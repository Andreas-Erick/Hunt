# Triage Labels

The skills speak in five triage roles. This repo's labels
match that vocabulary one-to-one:

- `needs-triage`: the maintainer needs to evaluate it
- `needs-info`: waiting on the reporter
- `ready-for-agent`: fully specified, ready for an agent
- `ready-for-human`: needs a person to implement
- `wontfix`: will not be actioned

When a skill names a role (for example "apply the
AFK-ready triage label"), use the label of the same name.
